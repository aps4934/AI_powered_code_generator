About the Project

This academic project explores the capabilities of Large Language Models (LLMs) in software development. By providing a structured interface for natural language to code compilation, the system assists in algorithmic prototyping and learning.

Developed as a major project by B.Tech Computer Science (AI&ML) students, the architecture utilizes a Flask REST backend to interface with the Gemini API, alongside a responsive front-end for seamless user interaction.
